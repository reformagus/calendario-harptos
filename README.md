# Calendário de Harptos em português brasileiro

Versão adaptada do calendário publicado em `calendar.html` no projeto [DungeonMasterTools.github.io](https://github.com/DungeonMasterTools/DungeonMasterTools.github.io), originalmente criado por DungeonMasterTools e distribuído sob a licença MIT. O aviso completo e os termos da licença estão em [LICENSE](LICENSE).

A interface foi redesenhada e traduzida para português brasileiro. A página apresenta os doze meses, os dias de cada mês, as festividades intercaladas e a regra de Shieldmeet descrita pela fonte. Nomes próprios do cenário foram mantidos quando apropriado; traduções explicativas foram acrescentadas para facilitar o uso à mesa.

Elementos de cenário de Forgotten Realms e Dungeons & Dragons pertencem aos respectivos titulares. Este é um projeto de fã, sem vínculo ou aprovação oficial.

## Uso

Abra `index.html` localmente ou publique a pasta em um serviço de hospedagem estática compatível com GitHub Pages. `calendar.html` conserva o endereço da página de calendário original; âncoras como `#Mirtul` selecionam o mês correspondente.
